PROLOGUE · 開場

串列加串列是接起來，陣列加陣列才是逐元素相加 課程 Lab Ch2 · 儲存格 21–34

統計程式從頭到尾都在做同一件事：對一整排數字做同一個運算。 算殘差是每一筆都減掉配適值，算標準化是每一筆都減平均再除標準差。 Python 內建的串列（list）做不到這件事。它的 + 是「接起來」，不是「加起來」。

一句話 串列的 + 是串接，陣列的 + 是逐元素相加。這一個差別就是你需要 NumPy 的全部理由。
›按「切換」看同一組數字在兩種容器裡的行為。
課程／lab 資料依 Ch02 lab 的 list 與 ndarray 加法結果重繪。
兩種 +
上排是串列：x + y 把 y 接在 x 後面，長度變成 6。
下排是陣列：x + y 把對齊的元素相加，長度還是 3。
目前的結果
x + y（串列）—
x + y（陣列）—
長度—
為什麼串列要這樣設計
串列裝的東西可以是任何型別，數字、字串、另一個串列混在一起都行，所以「相加」對它沒有意義，只能定義成串接。陣列規定整塊都是同一個型別，才談得上逐元素運算。
串列的 + 是串接
x = [3, 4, 5] x y = [4, 9, 7] x + y
預期輸出
[3, 4, 5, 4, 9, 7]

注意輸出是 [3, 4, 5, 4, 9, 7]，六個元素，不是三個。

來源：Ch02-statlearn-lab-zh.ipynb · 儲存格 21、23
陣列的 + 是逐元素相加
x = np.array([3, 4, 5]) y = np.array([4, 9, 7]) x + y
預期輸出
array([ 7, 13, 12])

同一組數字，換成 np.array 之後 + 的意思就變了。

來源：Ch02-statlearn-lab-zh.ipynb · 儲存格 31、34
常見疑問
那我可以只用 pandas，不學 NumPy 嗎？
不行，而且你已經在用了。DataFrame 的每一欄底下就是一個 NumPy 陣列，df['mpg'].mean() 走的是 NumPy 的路。pandas 幫你管欄名與索引，真正算數字的還是 NumPy。
陣列比串列快在哪裡？
兩件事。一是記憶體連續：整塊同型別的數字排在一起，CPU 一次抓一批；串列存的是一堆指標，每個元素都要再跳一次。二是迴圈在 C 裡面跑：x**2 不會回到 Python 逐個平方。

ndim、dtype、shape：一個陣列的三個身分證欄位 課程 Lab Ch2 · 儲存格 36–48

一個陣列的身分由三個屬性決定：ndim（幾維）、dtype（裝什麼型別）、 shape（每一維多長）。看不懂錯誤訊息的時候，先把這三個印出來，八成就找到原因了。

PART 02 · reshape 與轉置

reshape 給的是同一塊資料的另一種看法 課程 Lab Ch2 · 儲存格 50–66

reshape 不搬資料。它給你的是同一塊記憶體的另一種讀法—— 六個數字排成一排，或排成兩列三欄，底下是同一塊。這件事不知道的話， 之後改了一個變數卻發現另一個也跟著變，會找很久。

觀念釐清
什麼時候會真的複製一份？
切片（A[1:3]）與 reshape 給的是檢視（view），不複製；花式索引（用整數串列或布林陣列去挑，例如 A[[1,3]]）與明確呼叫 .copy() 才會複製。不確定就 .copy()，安全比省記憶體重要。
為什麼 reshape 要傳一個 tuple？
因為形狀本來就是一個 tuple。x.reshape((2, 3)) 與 x.reshape(2, 3) 都可以，前者跟 shape 屬性的寫法一致，讀起來比較不會誤會。

PART 04 · 布林索引

用一排 True／False 挑列：統計程式最常見的選取法 課程 Lab Ch2 · 儲存格 162–176

統計程式裡挑資料，九成不是靠位置，是靠條件： 「馬力大於 150 的那些車」「訓練集的那些列」。做法是先算出一排 True／False， 再拿它去索引。這排布林值的長度必須跟那一維一樣長。

布林索引與整數索引不一樣 A[np.array([0,1,0,1])] 是整數索引，意思是「第 0、1、0、1 列」，會拿到四列而且有重複；A[np.array([False,True,False,True])] 才是布林索引，拿到兩列。長得很像，結果差很多。

PART 05 · 廣播

形狀不一樣也能相加：右對齊、補 1、拉伸 NumPy 文件 · 廣播規則課程 Lab Ch2 · 儲存格 68–72

形狀不一樣的兩個陣列也能相加，NumPy 會照一套固定規則把它們對齊，這叫廣播 （broadcasting）。標準化資料 (X - X.mean(0)) / X.std(0) 就是靠它—— 左邊是 (10, 3)，右邊是 (3,)，形狀不同卻能直接相減。

廣播三步驟 ① 右對齊兩個 shape；② 缺的維度補 1；③ 長度是 1 的維度拉伸到對方的長度。任何一維兩邊既不相等、也沒有一邊是 1，就報錯。

為什麼 np.var 預設除以 n？
NumPy 的立場是「我算的是這批數字本身的變異數」，那就是除以 n。統計上要估母體變異數才需要 n−1。pandas 的 .var() 預設是 ddof=1，兩邊不一致——同一份資料用兩個套件算會得到不同的數字，這是很經典的踩雷點。

np.var(y) vs y.var()沒差，兩個都是除以 n

三個一定要記住的觀念 1. shape 是 (列, 欄)，列在前。看不懂錯誤訊息就先印 shape。
2. reshape 與切片給的是檢視，花式索引與布林索引給的是複本。不確定就 .copy()。
3. axis 指的是被摺掉的那一維。axis=0 往下摺得到欄的統計量，axis=1 往右摺得到列的統計量。
