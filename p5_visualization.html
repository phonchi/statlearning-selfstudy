Seaborn 函式地圖：先選問題，再選控制層級

導論講義第 29 頁把常用函式分成關係、分布、類別三個家族； 這是在分「你想看什麼」。每個家族又有不同控制層級：上層的 Figure-level 入口替你管理整張圖， 下層的 Axes-level 函式畫到一個座標系。家族與層級是兩個不同的面向。

關係（Relational）
看兩個變數如何一起變動
Figure-level：relplot

Axes-level

  • scatterplot：散佈圖
  • lineplot：折線圖

kind="scatter" 或 kind="line" 選擇畫法。

分布（Distributional）
看數值集中在哪裡、如何散開
Figure-level：displot

Axes-level

  • histplot：直方圖
  • kdeplot：密度圖
  • ecdfplot：經驗累積分布圖
  • rugplot：以小刻度標出觀測位置

kind 可選 "hist"、"kde"、"ecdf"。 小刻度用 rug=True 加上，不是 kind="rug"。

類別（Categorical）
比較不同組別的觀測或摘要
Figure-level：catplot

Axes-level

  • stripplot、swarmplot：逐筆畫點
  • boxplot、violinplot：分布摘要
  • pointplot、barplot：估計值與誤差線

例如 kind="box" 選箱形圖。 本頁另補 countplot：各組筆數，可用 kind="count"；它未列在講義這張分類圖中。

以 relplot、displot、catplot 為例， kind 決定每個子圖的畫法，row／col 則依變數分面， 把各組排成不同列／欄。三者回傳 FacetGrid；沒指定分面時，也可以只畫一個子圖。 Figure-level 不等於「一定有多個子圖」。

下面是語法示意，沿用本頁開頭載入的 tips；先執行 imports 與資料載入。 第一種交給 Seaborn 依吸菸與否分面，第二種把圖放到自己指定的 ax；不另列實跑輸出。

# Figure-level：kind 選散佈圖，col 將各組分開 g = sns.relplot(data=tips, x="total_bill", y="tip", kind="scatter", col="smoker") # Axes-level：指定要畫到哪個座標系 fig, ax = plt.subplots() sns.scatterplot(data=tips, x="total_bill", y="tip", ax=ax)

講義第 29 頁還列了下面三類。它們分別提供多視角組圖、迴歸與殘差圖，以及矩陣圖；可依用途與控制層級查找。

用途Axes-levelFigure-level／回傳的管理物件
多個視角：同時看關係與各欄分布由管理物件安排多個座標系jointplot → JointGrid；pairplot → PairGrid
迴歸與殘差：看趨勢及偏離趨勢的情形regplot、residplotlmplot → FacetGrid
矩陣：用顏色看各格數值，需要時依分群排列heatmapclustermap → ClusterGrid

jointplot 以一對變數為主，加上兩側的分布；pairplot 組合多對變數， 兩者各自管理多個 Axes。clustermap 則連同分群樹與熱圖一起管理。 若你已建立自己的 subplots，應選可接收 ax= 的 Axes-level 函式。

分類依據：導論講義第 29 頁與 Seaborn 官方函式總覽。 函式名稱都可點回官方 API 文件。

PART 02 · 看一個變數的分布

直方圖的 bins 與密度圖的頻寬會改變你的結論 課程 Lab Ch1 · 儲存格 105–111

看一個變數的分布有兩種標準做法：直方圖與密度圖。兩者都有一個你必須自己決定的參數—— 直方圖是 bins（切幾格），密度圖是頻寬（平滑多少）。調整這個參數， 同一份資料可能看起來有兩個峰或只有一個。

依分析問題調整圖形 調參數之前先想好你要回答什麼問題。想看「有沒有兩群」就把 bins 調細一點；想看「大致集中在哪」就調粗一點。也要比較其他設定下的結果，確認看到的形狀是否穩定。
›先猜這份資料有幾個峰，再把 bins 從 4 拉到 40。

觀念釐清
regplot 幫我配了線，是不是就等於做了迴歸分析？
還需要後續分析。這個函式給你一條線與一條帶子，沒有係數、沒有 p 值、沒有診斷。要那些東西得用 statsmodels（P6 會講）。regplot 的用途是「先看看有沒有線性關係」。
熱圖看到兩個變數相關 0.9，該怎麼辦？
先想它們是不是本來就在量同一件事（例如 weight 與 displacement）。真的要放進同一個迴歸模型的話，第 3 章的共線性與第 6 章的收縮方法就是在處理這件事。
