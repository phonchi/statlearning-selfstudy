統計學習主島正課 11 章

沿著環島小徑依授課順序排列，可自由進入任何一章。

  1. 01 統計學習導論與 EDA 觀測塔 統計學習在做什麼、和相關領域如何分工；先看資料再建模，從探索式資料分析（EDA）讀懂 22 個資料集。 需要時可查閱：機率、平均與變異、pandas 資料框、視覺化
  2. 02 統計學習的基本框架 訓練／測試分岔路 Y = f(X) + ε 的基本框架：可縮減與不可縮減誤差、彈性與可解釋性、偏差–變異取捨，以及 Bayes 分類器與 KNN。 需要時可查閱：機率、平均與變異、分布與抽樣、NumPy 陣列
  3. 03 線性迴歸 迴歸斜坡 簡單與多元線性迴歸：係數的標準誤與 t 檢定、F 檢定、R²，以及質性變數、交互作用與共線性等常見問題。 需要時可查閱：從樣本推論母體、相關與迴歸〔選讀〕、建模 API
  4. 04 分類 雙色分類城門 邏輯斯迴歸、LDA、QDA 與 Naive Bayes；用混淆矩陣、ROC 與 AUC 比較分類結果，並延伸到 Poisson 迴歸。 需要時可查閱：條件機率與獨立、分布與抽樣、貝氏推論〔選讀〕、建模 API
  5. 05 重抽樣方法 Bootstrap 噴泉 驗證集法、LOOCV 與 k-fold 交叉驗證估計測試誤差；Bootstrap 重抽樣衡量估計量的不確定性。 需要時可查閱：分布與抽樣、從樣本推論母體、建模 API
  6. 06 線性模型選擇與正則化 修剪花園 變數很多時如何選模型：子集選擇與 Cp／AIC／BIC，Ridge 與 Lasso 正則化，以及 PCR 與 PLS 降維迴歸。 需要時可查閱：相關與迴歸〔選讀〕、NumPy 陣列、建模 API
  7. 07 超越線性 樣條拱橋 線性不夠用時：多項式、階梯函數、迴歸樣條、平滑樣條、局部迴歸，最後組成廣義可加模型（GAM）。 需要時可查閱：相關與迴歸〔選讀〕、視覺化
  8. 08 樹狀方法與集成學習 決策樹森林 迴歸樹與分類樹的分裂與剪枝；再用 Bagging、隨機森林與 Boosting 把許多棵樹集成為更穩定的預測。 需要時可查閱：分布與抽樣、建模 API
  9. 09 支持向量機 最大間隔圍牆 用超平面把兩群資料分開：最大邊界、軟邊界與 C、hinge loss，以及透過核技巧處理非線性邊界。 需要時可查閱：NumPy 陣列、建模 API
  10. 10 非監督式學習 群聚星球廣場 沒有標準答案的學習：主成分分析（PCA）、矩陣補全，以及 K-means 與階層式分群。 需要時可查閱：機率、平均與變異、NumPy 陣列、視覺化
  11. 11 深度學習（補充） 神經網路高塔 補充章：從單層到多層神經網路、卷積與循環網路，以及模型如何擬合與雙下降現象。本課未授課，供自學延伸。 需要時可查閱：NumPy 陣列、建模 API
