PROLOGUE · 開場

神經網路不是新東西：從線性模型長出隱藏層 ISLP §10 開頭

先講清楚這一章的定位：本課沒有教第 10 章。它不在考試範圍， 也沒有對應的講義與 lab。放上來是因為前面九章把「線性模型 → 加彈性 → 加正則化 → 換基底 → 集成」這條線走完之後，深度學習正好是同一條線的下一步，缺了它整本書會斷掉。

ISLP 用一個很不客氣的方式介紹神經網路：把式子攤開來看，它就是 線性模型套一層非線性再線性組合一次。單層網路的預測函數長這樣：

$$f(X) = \beta_0 + \sum_{k=1}^{K} \beta_k \, g\!\left(w_{k0} + \sum_{j=1}^{p} w_{kj} X_j\right) \tag{10.1}$$

把 g 換成恆等函數，整條式子會塌回線性迴歸：兩層線性組合疊起來還是線性組合。 所以真正做事的是 g，其餘都是熟面孔。

這一章的六個主題 1. 單層網路（§10.1）：一層隱藏層，非線性從哪裡進來。
2. 多層與 MNIST（§10.2）：疊第二層、softmax 輸出、參數量開始失控。
3. 卷積網路（§10.3）：權重共享與池化，把影像的結構寫進架構裡。
4. 文件分類與 RNN（§10.4–10.5）：順序有意義的時候，詞袋不夠用。
5. 怎麼配適（§10.7）：反向傳播、SGD、dropout。
6. 雙下降（§10.8）：參數比樣本還多，測試誤差為什麼還會再降一次。

還有一個貫串全章的問題，§10.6 專門處理：什麼時候該用深度學習、什麼時候不該。 ISLP 的立場很明確，Hitters 那個例子就是拿來說服你的——神經網路跟線性迴歸打平， 而線性模型看得懂、講得清。他們搬出奧坎剃刀：表現差不多的時候，挑簡單的那個。

PART 01 · 單層神經網路

一層隱藏層：非線性怎麼進來的 ISLP §10.1ESL §11.3

單層網路的結構只有三步：輸入做 K 組線性組合、每一組過同一個 g、 再把 K 個結果線性組合成輸出。中間那 K 個值 ISLP 叫 activation， 寫成 A_k：

$$A_k = h_k(X) = g\!\left(w_{k0} + \sum_{j=1}^{p} w_{kj} X_j\right), \qquad f(X) = \beta_0 + \sum_{k=1}^{K} \beta_k A_k \tag{10.2}$$

要估的參數是所有 w 與所有 β，總共 K(p+1) + (K+1) 個。 注意 w_{k0} 與 β₀ 這兩個截距在機器學習圈叫 bias—— ISLP 在註腳特別提醒，那跟偏差–變異取捨的「偏差」是兩回事，只是撞名。

g 的兩個常見選擇 Sigmoid：g(z) = eᶻ/(1+eᶻ)，把任何實數壓進 (0, 1)。 就是邏輯斯迴歸那個函數。缺點是 |z| 一大曲線就平掉，導數趨近 0，梯度傳不回去。
ReLU：g(z) = max(0, z)。負的歸零、正的原樣過。導數不是 0 就是 1， 算得快也不會消失，現代網路的預設。

Q：隱藏單元的個數 K 該怎麼選？

沒有公式，它是超參數，跟第 6 章的 λ、第 8 章的樹深度同一個地位，用交叉驗證或驗證集選。

但實務上的取法跟你想的可能不一樣：現代做法是先把 K 開大，再靠正則化（dropout、權重衰減、早停）把彈性收回來，而不是小心翼翼地找剛剛好的 K。原因在 §10.8：過度參數化的網路配上會找平滑解的 SGD，表現往往比「剛好夠用」的網路更好。

Q：為什麼要標準化輸入？

跟 SVM 與嶺迴歸的理由一樣：所有輸入共用同一個學習率與同一個權重衰減，尺度差很多時，數值大的那個變數會主宰梯度，小的那個幾乎不動。

官方 lab 的 Hitters 例子在 lasso 那條路上用 StandardScaler 包進 Pipeline，神經網路那條路則是先把整個 X 標準化再切訓練測試。要注意的是：標準化的統計量只能從訓練資料算，否則就是第 5 章講過的資料洩漏。

PART 02 · 多層與 MNIST

疊第二層之後：softmax 與 235,146 個參數 ISLP §10.2ESL §11.4–11.6

多加一層之後，第二層的輸入不再是 X，而是第一層的輸出 A^(1)。 式子還是那個式子，只是套了兩次：

$$A^{(1)}_k = g\!\left(w^{(1)}_{k0} + \sum_j w^{(1)}_{kj} X_j\right), \qquad A^{(2)}_\ell = g\!\left(w^{(2)}_{\ell 0} + \sum_k w^{(2)}_{\ell k} A^{(1)}_k\right)$$

MNIST 是十類別的問題，所以輸出層要吐十個數字再轉成機率。用的是 softmax：

$$f_m(X) = \Pr(Y = m \mid X) = \frac{e^{Z_m}}{\sum_{\ell=0}^{9} e^{Z_\ell}} \tag{10.13}$$

損失函數則是負的多項式對數似然，也就是交叉熵：

$$-\sum_{i=1}^{n} \sum_{m=0}^{9} y_{im} \log f_m(x_i) \tag{10.14}$$
softmax 是過度參數化的 把每個 Z_m 同時加上一個常數 c，分子分母各多一個 e^c， 約掉之後機率完全不變（這正是習題 2a）。所以 softmax 的解不唯一。 但實務上不成問題：正則化與 SGD 會把解限制在一個特定的地方。 同樣的事在第 4 章的多元邏輯斯迴歸也發生過，那裡的處理方式是挑一個類別當基準。

參數量是這一節的重點。MNIST 的輸入是 28×28 = 784 個像素， ISLP 用的架構是 784 → 256 → 128 → 10。光第一層就有 784×256 + 256 = 200,960 個參數， 三層加起來 235,146 個。對照組多元邏輯斯迴歸只需要 785×9 = 7,065 個， 差了 33 倍。

PART 03 · 卷積神經網路

把「哪裡」的資訊丟掉一部分：卷積與池化 ISLP §10.3

上一節把 28×28 攤平成 784 的那一刻，「這兩個像素相鄰」的資訊就沒了。 對影像來說這很浪費：一隻貓的耳朵出現在左上角還是右下角，都應該算是耳朵。 卷積網路把這個先驗直接寫進架構，做法有兩個。

CNN 的兩個動作 卷積層：拿一個小濾波器（例如 3×3）掃過整張圖， 每個位置算一次內積。同一個濾波器在所有位置共用同一組權重， 所以參數量跟影像大小無關，只跟濾波器大小有關。
池化層：把相鄰一小塊（例如 2×2）濃縮成一個值，最大池化取最大者。 它降解析度，也讓結果對小幅平移不敏感：刻意丟掉一些「在哪裡」，換取「有沒有」的穩健。

觀念釐清
Q：池化為什麼要「丟掉資訊」？那不是壞事嗎？

丟掉的是位置的精度，留下的是「這個特徵存不存在」。對分類來說後者才是重點——你要判斷這是不是一隻貓，不需要知道耳朵精確在第 137 個像素。

更實際的理由是它讓後面的層看得更廣。經過一次 2×2 池化，同樣一個 3×3 濾波器在原圖上涵蓋的範圍就變成兩倍。堆疊「卷積＋池化」等於一步步擴大視野：前面的層看邊緣與紋理，後面的層看得到整隻動物。官方 lab 的 CIFARModel 疊了四組，32×32 因此縮成 2×2。

Q：資料擴增算正則化嗎？

算，而且 ISLP §10.3.4 就是這樣定位它的。把訓練影像隨機翻轉、平移、縮放之後標籤不變，等於在告訴模型「這些變化不該影響答案」。這是一個很強的約束，跟嶺迴歸用懲罰項限制係數是同一種事，都在縮小模型能選的函數空間。

差別在於它是用資料表達的約束，不是用公式。好處是很容易加進任何模型；壞處是你得知道哪些變化是無害的（影像可以左右翻，手寫數字的 6 跟 9 就不能上下翻）。

lab §10.9.3 · 一個 building block 疊四次
class BuildingBlock(nn.Module): def __init__(self, in_channels, out_channels): super(BuildingBlock, self).__init__() self.conv = nn.Conv2d(in_channels=in_channels, out_channels=out_channels, kernel_size=(3,3), padding='same') self.activation = nn.ReLU() self.pool = nn.MaxPool2d(kernel_size=(2,2)) def forward(self, x): return self.pool(self.activation(self.conv(x)))\n\nclass CIFARModel(nn.Module): def __init__(self): super(CIFARModel, self).__init__() sizes = [(3,32), (32,64), (64,128), (128,256)] self.conv = nn.Sequential(*[BuildingBlock(in_, out_) for in_, out_ in sizes]) self.output = nn.Sequential(nn.Dropout(0.5), nn.Linear(2*2*256, 512), nn.ReLU(), nn.Linear(512, 100)) def forward(self, x): val = self.conv(x) val = torch.flatten(val, start_dim=1) return self.output(val)

BuildingBlock 就是「卷積 → ReLU → 最大池化」三件套。通道數一路 3 → 32 → 64 → 128 → 256 加倍，空間尺寸則被池化一路砍半：32 → 16 → 8 → 4 → 2。解析度換通道數是 CNN 的標準節奏。

PART 05 · 怎麼配適

反向傳播、SGD、dropout：非凸問題怎麼還是解得動 ISLP §10.7ESL §11.4 · 進階

前面都在講模型長什麼樣，這一節講怎麼把參數估出來。目標函數以量化反應為例：

$$R(\theta) = \frac{1}{2} \sum_{i=1}^{n} \left(y_i - f_\theta(x_i)\right)^2 \tag{10.22}$$

問題在於這個 R(θ) 不是凸函數。線性迴歸有閉式解、 邏輯斯迴歸的對數似然是凹的所以有唯一最大值，神經網路兩個都沒有： 它有很多局部極小，而我們只能用梯度下降慢慢滑下去、 接受「找到一個夠好的解」而不是「找到最好的解」。

圖表需要連網載入 Chart.js。此圖的重點：同一個函數、同一個學習率，只是起點不同，梯度下降就會滑進不同的局部極小，這就是非凸最佳化的日常。

每一步做 β ← β − ρ·R′(β)，其中 R′(β) = cos(β) + 1/10。導數為 0 的地方就是駐點，梯度下降只保證滑到某一個駐點，不保證是最低的那個。
三個讓它跑得動的技巧 反向傳播：用連鎖律由輸出往回逐層算梯度， 重複利用前一層算好的中間量。它不是另一種演算法，只是把梯度算得夠便宜—— 成本跟一次前向傳播同一個量級。
隨機梯度下降：每一步只用一小批（minibatch）樣本估梯度。 除了便宜，取樣雜訊本身還有正則化效果，也幫忙跳出不好的局部極小。
Dropout：訓練時隨機把一部分單元設成 0，剩下的按比例放大。 每一批看到的都是不同的子網路，沒有單元能依賴特定同伴。 ISLP 說它的精神接近隨機森林，都靠隨機性打散相關性。

還有一個常被忽略的正則化手段：早停。 訓練誤差會一路降，驗證誤差則通常先降後升；在轉折點停下來， 效果跟加懲罰項類似。官方 lab 的 ErrorTracker 回呼就是在記錄這條曲線。

觀念釐清
Q：非凸為什麼還敢用？局部極小不會害死我們嗎？

會，但沒有想像中嚴重，原因有幾個層次。

第一，實務上在高維空間裡，真正的「壞局部極小」比想像中少：更常見的是鞍點，而 SGD 的雜訊很容易把你推離鞍點。第二，我們要的不是訓練誤差的全域最小，而是測試誤差夠低；訓練誤差的全域最小很可能就是嚴重過度配適的那個點。

第三，這是誠實的部分：它就是會隨機。同一份資料換一個隨機種子，跑出來的網路不一樣、測試誤差也不一樣。官方 lab 每次訓練前都呼叫 seed_everything，並在 Trainer 裡設 deterministic=True，就是為了讓結果可重現。

Q：dropout 為什麼要「按比例放大」？

因為訓練與預測時的行為必須對得起來。訓練時如果丟掉 40% 的單元，下一層收到的加總平均就只剩 60%；預測時所有單元都在，加總會突然變大 1/0.6 倍，模型等於面對一個沒見過的輸入分布。

解法是訓練時把留下來的值除以 0.6，讓期望值維持不變，預測時就什麼都不用做。這叫 inverted dropout，也是 nn.Dropout 的做法。順帶一提，這就是為什麼 model.eval() 很重要——它會關掉 dropout；忘了呼叫的話預測會帶著隨機性。

(C) 會更快，因為少了每個批次的額外開銷
PART 06 · 雙下降與該不該用

參數比樣本多還會變好？以及什麼時候該收手 ISLP §10.8ISLP §10.6

從第 2 章開始，這本書一直在講同一件事：測試誤差對模型彈性是 U 形的， 所以不要把訓練誤差壓到 0。§10.8 要示範一個看起來完全相反的現象。

設定很簡單，用的還是第 7 章的自然樣條，跟神經網路無關： n = 20 筆資料來自 Y = sin(X) + ε，X 均勻分布在 [−5, 5]、ε 的標準差是 0.3。 然後配自由度 d 的自然樣條，讓 d 從 2 一路加到 100。

d = 20 時自由度等於樣本數，樣條剛好穿過每一個點，訓練誤差變成 0： 這就是內插門檻。d 再往上，最小平方解不再唯一（有無限多組係數都能穿過）， 課本挑的是係數平方和最小的那一組，也就是最小範數解。

圖表需要連網載入 Chart.js。此圖的重點：測試誤差在 d = n = 20 附近衝到最高，然後隨著自由度繼續增加又降下來，這就是雙下降。訓練誤差則在 d = 20 之後一直是 0。
›紅線是測試誤差、藍線是訓練誤差。注意 d = 20 那根尖峰。

兩個要注意的地方
d = 20 只有一種方式穿過 20 個點，而那一種很極端；d = 42 有無限多種，挑最平滑的那一種當然溫和得多。切到配適曲線會看到 Σβ² 在 d = 20 最大、之後反而變小。
另外，訓練誤差在 d ≥ 20 之後真的是 0（10⁻²⁸ 量級），但對數軸畫不出 0，所以藍線被壓在 10⁻⁵ 的底線上。
雙下降沒有推翻偏差–變異取捨 ISLP 把話講得很白：橫軸畫的是「基底函數的個數」， 而那並沒有正確反映內插模型真正的彈性。d = 42 的最小範數樣條， 變異其實比 d = 20 的樣條小，它只是用比較多的基底去表達一個比較平滑的函數。
另外兩件要記住的事：這本書裡大多數方法不會出現雙下降 （正則化方法通常不內插資料）；而且在這個例子裡， 如果改用嶺迴歸配樣條並好好選懲罰項，測試誤差還會更低。 雙下降不是「參數愈多愈好」的許可證。

這跟深度學習的關係在最後一段：訓練神經網路時我們常常用遠多於樣本數的參數， 而且真的能把訓練誤差壓到 0 還表現得不錯。ISLP 的解釋是 SGD 天生就偏好找到平滑的內插解，效果類似上面那個最小範數。 這在訊噪比高的問題（自然影像辨識、語音）上特別成立。

順帶把 §10.6 的建議收在這裡。ISLP 對「該不該用深度學習」的答案是： 先跑簡單模型當基準，讓深度學習去證明自己值得。 Hitters 那個例子就是示範：三個模型表現相近時，選看得懂的那個。 但反過來，CIFAR 的影像與 IMDB 的文字這種輸入本身有結構、樣本量又大的問題， 線性模型從一開始就沒有機會。

三個一定要記住的觀念 1. 神經網路是線性模型套非線性再組合一次。 把 g 拿掉就退回線性迴歸；非線性只能從 g 進來，加總本身不會產生它。
2. 權重共享是 CNN 與 RNN 的共同心臟。 一個在空間上共享、一個在時間上共享，兩者都是把「結構」寫進架構而不是靠資料學。
3. 雙下降不是「參數愈多愈好」。 第二次下降來自最小範數解比較平滑，不是來自參數變多本身； 同一個例子改用嶺迴歸還會更好。
