# 三路全文審讀紀錄

基準：0f98dbf。三位原生代理各自以讀者角度完整閱讀全部正文、收合區、圖說、Lab說明、39個內嵌選項回饋、29張詞彙卡，以及外部題庫1題的4個回饋。

- reader_continuity：以剛學完 regression 的讀者檢查先備、首次定義、正文與收合區的銜接，並抽查 regression 的相關內容。
- reader_consistency：檢查符號、術語、測驗、圖說與卡片之間是否一致。
- reader_correctness：對照講義及 ISLP，核對模型條件、數學推導、互動允許範圍及數值解讀。
