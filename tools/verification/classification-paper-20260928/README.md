# Classification：依 tutorial 精修直覺與連結

使用者指定 https://arxiv.org/pdf/1906.02590，並明確要求重點是直覺和連結、不要太多推導。

## 精修

- Bayes：從選某類時的條件誤判機率，解釋為何要取最大後驗。
- 判別分數：說明分數本身不是機率，以唯一新增的獨立公式softmax接回logistic。
- 距離：解釋類內尺度、相關性與Mahalanobis距離；連回前章看尺度的想法。
- 白化：區分共同座標變換與後續的降維投影。
- Fisher：先講類間與類內散布的直覺，再連到既有公式；比較PCA的目標，分清方向與切點。
- QDA：用資料雲形狀解釋距離、散布體積及先驗，避免誤解成單純最近中心。
- 同步2張詞彙卡，維持29張；保留原有推導、Lab與烘焙資料。
