## 最值得採用：六處短段落

### 1. Bayes 先給決策原則，LDA/QDA 再提供分布

位置：P03 Bayes 公式後、類內常態假設前。

建議文字：
「給定同一筆 x，若選第 k 類，判錯的機率就是 1−P(Y=k|X=x)。在每種誤判代價相同時，選後驗機率最大的類別，就能讓這個條件錯誤率最小。這是 Bayes 決策原則。LDA 和 QDA 接著用類內常態模型估計這些機率；用資料估出的規則仍會有估計誤差，不能直接當成已知真實分布的最佳規則。」

這是由 0–1 loss 直接推得的教學連結。論文 §2 的邊界討論可作導讀，但不要照搬其「交點必在均值之間」的敘述。

### 2. 分數如何回到 logistic / softmax

位置：多變數判別函數之後、LDA 和 logistic 的比較之前。

建議文字：
「判別分數用來比較類別，本身不是機率。把每類分數取指數，再除以全部類別的總和，就能回到後驗機率：
\[P(Y=k\mid x)=\frac{e^{\delta_k(x)}}{\sum_\ell e^{\delta_\ell(x)}}.\]
這正是前面介紹的 softmax。二分類時，兩類分數之差就是 log-odds，通過 logistic 函數後得到其中一類的機率。因此 LDA 與 logistic regression 可以有相同的機率函數形式；前者從類內分布算出係數，後者直接從類別結果估計係數。」

此式由頁面既有 Bayes 與 δ 定義直接化簡，沒有新增模型假設。官方數學教材 §1.2.2 的 log posterior = linear score + Cst 是精確依據。論文 §5 式(28)、(31)與§9有相同連結主題，但原文稱 δ 為 scaled posterior 不夠精確。

### 3. 先用日常距離解釋 Mahalanobis，再進白化

位置：FLDA 收合區距離公式之前。

建議文字：
「離類別中心同樣遠，意義不一定相同：沿著同類資料本來就很分散的方向，偏離一些並不稀奇；沿著很集中的方向，偏離同樣距離就比較少見。Mahalanobis 距離把各方向的散布與相關性算進去。LDA 用共同的類內共變異數衡量所有類別，所以每一類使用相同的尺度。白化把這個尺度調整直接做在座標上，調整後便能用普通距離比較。」

官方 §1.2.2.2–1.2.3 支持共同尺度、先驗與白化。論文 §7 pp.5–6 的直覺有啟發，但應避免把「變異大」直接說成「該類更可能」。

### 4. 白化與降維是兩步

位置：白化敘述後，K−1 維投影前。

建議文字：
「白化先調整座標的方向與尺度，完整白化仍保留 p 個維度。接著才把資料投影到各類中心所在的空間。各類中心都沒有差異的垂直方向，對每類增加相同的距離，因此不影響分類比較。」

這可消除現有長公式前的概念跳躍，不必再增加公式。維持現有『共用類內共變異數』措辭，不能說整體 X 的共變異數變成 I，因為類間散布仍存在。官方 §1.2.3；論文 §7–8 是相關主題。

### 5. Fisher 與 PCA：目標不同；投影方向不等於切點

位置：FLDA 開頭「尋找類別平均分得開、同類資料又集中」之後。

建議文字：
「可以想像兩類資料都在水平方向拉得很長，類別中心卻主要在垂直方向分開。PCA 不看標籤，可能保留散布較大的水平方向；Fisher 同時看類別中心的差異與類內散布，會偏好有助區分類別的方向。找到方向後，仍要決定投影值在哪裡切開。先驗不同或誤判成本不同，切點會移動，方向未必改變。」

此例是独立構造的直覺例，不是論文的模擬结果。官方 PCA/LDA 例支持兩個目標的差異。現有頁面已說方向不等於切點；宜整合替換，不要重複新增同一提醒。

### 6. QDA 的三部分：偏離程度、散布體積、先驗

位置：P05 QDA 判別函數之後。

建議文字：
「QDA 讓各類依自己的散布衡量 x 離中心多遠，但不能只選 Mahalanobis 距離最小的類別。判別分數還包含共變異數行列式與先驗：同樣的標準化距離下，散布較廣的分布會把機率分散到更大範圍，密度較低；先驗則反映類別原本的比例。LDA 的散布形狀相同，所以共同的體積項可從比较中消去；QDA 要保留。」

獨立算例（若要採用，最多一句）：一維同中心、相同先驗、標準差 1 與 2，在共同中心兩個標準化距離都為 0，但標準差 1 的密度是另一類的 2 倍。此例直接由常態密度得到，能說清楚為什麼 QDA 不能只比距離。來源：官方 §1.2.2.1，論文 §5 式(28)、§7 式(43)。

## 不納入／來源需校正

不新增 kernel PCA、MDS、manifold learning、likelihood-ratio test 或新模擬章節。這些會偏離使用者要的主線直覺。

原文需避免照搬的核對點（屬數學檢查，不作學生頁面勘誤清單）：

- p.2 式(9)–(10)：類先驗不是類內密度在 x 的值。
- p.1–2 單一門檻只適用特定情境；異變異 Gaussian 可能有兩個邊界，先驗不等也可能把邊界移出兩均值之間。
- pp.3–4 式(25)–(27)：二次係數必須是逆矩陣之差，不能是差的逆矩陣；現有 HTML 已正确。
- p.5 式(36)：MLE 共變異數加權與不偏 pooled 不能混用；現有頁面分母正確。
- pp.5–6：先驗加入的是 log-score 的加法修正；不是把距離直接乘先驗。QDA 的 log determinant 項不可略掉來聲稱完全等同最近中心。
- p.7 式(52)–(54)：把向量方向寫成矩陣；現有 W^{-1}(mean difference) 正確。Fisher 準則本身不需 Gaussian，與生成式 LDA 分類相同還需相同尺度及切點。
- p.7 式(56)：使用 Bernoulli 0/1 形式卻標 ±1，不能照搬。
- pp.8–9：Bayes 規則的最佳性須指真實機率與指定損失；估計模型不自動最佳。分類 threshold 也不能直接查 chi-square 表。
